# n8n-nodes-beehiiv

This is an n8n community node for the Beehiiv API V2.

## Installation

Follow the [installation guide](https://docs.n8n.io/integrations/community-nodes/installation/) in the n8n documentation.

## Credentials

You will need a Beehiiv API Key. You can generate one in your Beehiiv account settings under **Settings > API**.

## Operations

### Publication
- **Get All**: Retrieve all publications associated with the API key.

### Subscription
- **Create**: Create a new subscription for a publication.
- **Get All**: Retrieve all subscriptions for a publication.

### Post
- **Get All**: Retrieve all posts for a publication.

## Development

1. Clone the repository
2. Run `npm install`
3. Run `npm run dev` to start n8n with the node loaded for local testing.
